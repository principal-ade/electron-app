   - GitCommitHistoryPanel mixes theme usage with hardcoded values
   
2. READABILITY IMPACT
   - 135 hardcoded instances scattered across panels makes it hard to
     understand type hierarchy at a glance
   
3. THEME SYSTEM OPPORTUNITY
   - Current theme has fontSizes[0-2] but missing semantic names
   - No fontWeights defined in theme
   - No typography/semantic style helpers
   
4. MONOSPACE INCONSISTENCY
   - Some panels use 'monospace' (hardcoded)
   - Others use theme.fonts.monospace (correct)
   - Needs standardization

5. ACCESSIBILITY RISK
   - No single place to verify font sizes meet WCAG standards
   - Cannot easily adjust sizing for accessibility needs
