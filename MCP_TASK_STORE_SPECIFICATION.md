# MCP Task Store Specification

## Overview

This document specifies a new persistent store for tracking MCP tasks submitted through the Principal MCP Bridge. Currently, tasks are submitted via HTTP endpoints but there's no centralized tracking of submission history, making it difficult to know what tasks have been received and their current state.

## Problem Statement

**Current Behavior:**
- Tasks are submitted to `POST localhost:3044/tasks/submit` or `/dependencies/submit`
- Tasks are written directly to Memory Palace files in dependency repositories
- If dependency resolution fails, tasks are lost
- No historical record of task submissions
- No way to track tasks across all repositories from a central location
- Users report tasks as "submitted" but can't find them later

**Desired Behavior:**
- All task submissions should be logged to a persistent store
- Track submission status, resolution status, and task location
- Provide queryable history of all MCP task submissions
- Enable UI panel to display all tasks (Milestone 2)

---

## Architecture

### Store Integration

Following the existing Multi-Store Manager pattern documented in `STORE_INFRASTRUCTURE_ANALYSIS.md`:

```
MCP Task Submission Flow
    ↓
HTTP Request → PrincipalMCPBridge
    ↓
1. Generate taskId
2. Store submission in MultiStoreManager (NEW)
3. Attempt dependency resolution
4. Write to Memory Palace (if resolved)
5. Update store with resolution status (NEW)
    ↓
Return response
```

### Storage Layer

**Namespace**: `mcp-tasks`
**Provider**: `ElectronStoreLocalStorageProvider`
**Persistence**: JSON file in Electron user data directory

## Data Model

### MCPTaskSubmission Interface

```typescript
/**
 * Represents a single MCP task submission received through the Principal MCP Bridge
 */
interface MCPTaskSubmission {
  // Identity
  taskId: string;                    // Generated by bridge: "task-{timestamp}-{random}"
  submittedAt: number;               // Timestamp when task was received

  // Task Content
  dependencyId: string;              // Target dependency identifier
  taskSummary: string;               // Brief task description
  taskDetails: string;               // Full task details
  priority?: 'low' | 'normal' | 'high' | 'critical';
  tags?: string[];
  anchors?: string[];
  repositoryRoot?: string;           // Optional repository hint from submitter

  // Resolution Status
  resolutionStatus: MCPTaskResolutionStatus;

  // Resolution Results
  dependencyResolved: boolean;       // Whether dependency was found
  dependencyRepository?: string;     // Full path to resolved dependency
  taskPath?: string;                 // Full path to written .task.md file
  taskWritten: boolean;              // Whether task was written to Memory Palace

  // Error Tracking
  error?: string;                    // Error message if submission failed
}

/**
 * Task resolution status lifecycle
 */
type MCPTaskResolutionStatus =
  | 'pending'        // Just received, not yet processed
  | 'resolved'       // Dependency found, task written to Memory Palace
  | 'unresolved'     // Dependency not found, task not written
  | 'failed';        // Error during processing
```

## Implementation Components

### 1. Store Service Layer

**File**: `src/main/stores/MCPTaskStore.ts` (NEW)

```typescript
import { MultiStoreManager } from './MultiStoreManager';
import { MCPTaskSubmission } from '../types/mcp-tasks';

/**
 * Simple service for managing MCP task submissions in the persistent store
 */
export class MCPTaskStore {
  constructor(private storeManager: MultiStoreManager) {}

  /**
   * Record a new task submission
   */
  async addTask(submission: Omit<MCPTaskSubmission, 'taskId' | 'submittedAt'>): Promise<MCPTaskSubmission> {
    const store = this.storeManager.getStore('mcp-tasks');
    const data = await store.get();

    const task: MCPTaskSubmission = {
      ...submission,
      taskId: this.generateTaskId(),
      submittedAt: Date.now(),
      resolutionStatus: submission.resolutionStatus || 'pending',
      dependencyResolved: submission.dependencyResolved || false,
      taskWritten: submission.taskWritten || false,
    };

    data.tasks.push(task);
    await store.set(data);

    return task;
  }

  /**
   * Get all tasks (sorted by most recent first)
   */
  async getAllTasks(): Promise<MCPTaskSubmission[]> {
    const store = this.storeManager.getStore('mcp-tasks');
    const data = await store.get();

    return [...data.tasks].sort((a, b) => b.submittedAt - a.submittedAt);
  }

  /**
   * Get a single task by ID
   */
  async getTask(taskId: string): Promise<MCPTaskSubmission | null> {
    const store = this.storeManager.getStore('mcp-tasks');
    const data = await store.get();
    return data.tasks.find(t => t.taskId === taskId) || null;
  }

  /**
   * Update an existing task
   */
  async updateTask(taskId: string, updates: Partial<MCPTaskSubmission>): Promise<MCPTaskSubmission | null> {
    const store = this.storeManager.getStore('mcp-tasks');
    const data = await store.get();

    const taskIndex = data.tasks.findIndex(t => t.taskId === taskId);
    if (taskIndex === -1) return null;

    data.tasks[taskIndex] = {
      ...data.tasks[taskIndex],
      ...updates,
    };

    await store.set(data);
    return data.tasks[taskIndex];
  }

  /**
   * Delete a task by ID
   */
  async deleteTask(taskId: string): Promise<boolean> {
    const store = this.storeManager.getStore('mcp-tasks');
    const data = await store.get();

    const initialLength = data.tasks.length;
    data.tasks = data.tasks.filter(t => t.taskId !== taskId);

    if (data.tasks.length < initialLength) {
      await store.set(data);
      return true;
    }

    return false;
  }

  private generateTaskId(): string {
    return `task-${Date.now()}-${Math.random().toString(36).substring(2, 9)}`;
  }
}
```

### 2. Bridge Integration

**File**: `src/main/principal-mcp/PrincipalMCPBridge.ts` (MODIFIED)

Add store tracking to the existing `handleTaskSubmission` method:

```typescript
import { MCPTaskStore } from '../stores/MCPTaskStore';

export class PrincipalMCPBridge {
  private mcpTaskStore: MCPTaskStore;

  constructor(
    private repositoryMonitoring: RepositoryMonitoringManager,
    private storeManager: MultiStoreManager
  ) {
    this.mcpTaskStore = new MCPTaskStore(storeManager);
  }

  async handleTaskSubmission(
    dependencyId: string,
    taskSummary: string,
    taskDetails: string,
    options: {
      repositoryRoot?: string;
      priority?: 'low' | 'normal' | 'high' | 'critical';
      tags?: string[];
      anchors?: string[];
    } = {}
  ): Promise<any> {
    // 1. Record submission to store FIRST
    const taskSubmission = await this.mcpTaskStore.addTask({
      dependencyId,
      taskSummary,
      taskDetails,
      ...options,
      resolutionStatus: 'pending',
      dependencyResolved: false,
      taskWritten: false,
    });

    try {
      // 2. Attempt dependency resolution (EXISTING CODE)
      const resolutionResult = await this.repositoryMonitoring.resolveDependency(
        dependencyId,
        options.repositoryRoot
      );

      // 3. Handle resolution results
      if (resolutionResult.dependency) {
        // Dependency found - write to Memory Palace
        const taskPath = await this.writeToMemoryPalace(
          resolutionResult.dependency.path,
          taskSubmission.taskId,
          taskSummary,
          taskDetails
        );

        // Update store with success
        await this.mcpTaskStore.updateTask(taskSubmission.taskId, {
          resolutionStatus: 'resolved',
          dependencyResolved: true,
          dependencyRepository: resolutionResult.dependency.path,
          taskPath,
          taskWritten: true,
        });

        return {
          success: true,
          taskId: taskSubmission.taskId,
          taskWritten: true,
          taskPath,
          dependencyRepository: resolutionResult.dependency.path,
        };
      } else {
        // Dependency not found
        await this.mcpTaskStore.updateTask(taskSubmission.taskId, {
          resolutionStatus: 'unresolved',
          dependencyResolved: false,
          taskWritten: false,
        });

        return {
          success: false,
          taskId: taskSubmission.taskId,
          taskWritten: false,
          error: 'Dependency not found',
        };
      }
    } catch (error) {
      // 4. Handle errors
      await this.mcpTaskStore.updateTask(taskSubmission.taskId, {
        resolutionStatus: 'failed',
        error: error.message,
      });

      throw error;
    }
  }
}
```

### 3. IPC Handlers

**File**: `src/main/stores/mcpTaskStoreHandlers.ts` (NEW)

```typescript
import { ipcMain } from 'electron';
import { MCPTaskStore } from './MCPTaskStore';

export enum MCPTaskStoreAPIEvent {
  GET_ALL_TASKS = 'mcp-task-store:get-all-tasks',
  GET_TASK = 'mcp-task-store:get-task',
  DELETE_TASK = 'mcp-task-store:delete-task',
}

export function registerMCPTaskStoreHandlers(mcpTaskStore: MCPTaskStore) {
  ipcMain.handle(MCPTaskStoreAPIEvent.GET_ALL_TASKS, async () => {
    return await mcpTaskStore.getAllTasks();
  });

  ipcMain.handle(MCPTaskStoreAPIEvent.GET_TASK, async (event, taskId: string) => {
    return await mcpTaskStore.getTask(taskId);
  });

  ipcMain.handle(MCPTaskStoreAPIEvent.DELETE_TASK, async (event, taskId: string) => {
    return await mcpTaskStore.deleteTask(taskId);
  });
}
```

## Error Handling

### Bridge Level
- Store submission failures should NOT block task processing
- Log store errors but continue with Memory Palace write

### Example Error Handling
```typescript
try {
  await mcpTaskStore.addTask(submission);
} catch (error) {
  console.error('Failed to store MCP task submission:', error);
  // Continue with task processing - don't block
}
```
